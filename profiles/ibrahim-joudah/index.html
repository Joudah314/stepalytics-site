Agentic AI job-market monitoring system

2026 · Independent project · designed, built and run by me

Problem
Good jobs appear on hundreds of different sites, and the best ones fill fast.
What I built
An agentic AI system that watches thousands of companies and other job sources around the clock, uses LLMs to judge which jobs fit, and sends notifications to phone.
Result
New openings are found within minutes, the AI’s judgement is measured against people’s, and a machine-learning filter cuts the number of paid AI calls.

Key facts

  • Agentic AI with LLMs (GenAI): an end-to-end system in Python and SQL on a cloud server, running 24/7. It collects job ads from multiple sources, uses LLMs to screen and evaluate each one, and sends notifications to phone.
  • LLM evaluation: I compared the AI’s ratings with human judgements, so its decisions can be trusted and improved over time.
  • Machine learning and statistics: a machine-learning model (XGBoost) reduces paid AI calls; it was tested safely in shadow mode before switching on. Bayesian statistical modelling keeps monitoring fast while keeping server load low.
  • Production-grade: about 1,300 automated tests, CI/CD with Git, monitoring and alerts, cost tracking, and encrypted backups.

Python · SQL · LLMs / GenAI · XGBoost · Bayesian modelling · cloud · CI/CD

Predicting survey qualification rates with LLMs

2026 · Applied AI · predictive modelling

Problem
How many people will qualify for a new consumer survey, when the topic has no past data to learn from?
What I did
Asked a large language model (LLM) for a first estimate from the question wording and location alone, and treated it as data to correct rather than as truth. An R and Python pipeline then combined those estimates with text embeddings and machine learning (XGBoost).
Result
In cross-validation on held-out categories, prediction error (RMSE) was 21% lower than the calibrated LLM estimate alone. I translated the results into business terms: how many people a survey would need to recruit to fill its quota, and a rule that flags qualifying questions few people are likely to pass.

R · Python · LLMs · text embeddings · XGBoost · cross-validation

StepAlytics Activity Explorer

2026 · Personal project · public dashboards

Problem
Which patterns in a year of step-tracker data are real, and how much do the weather and a program change daily activity?
What I did
Built Python and SQL (DuckDB) workflows with data-quality checks; measured the weather’s effect with regression and the program’s effect with a before-and-after time-series design (interrupted time series, checked with placebo tests); forecast the next day’s activity, tested by time-series cross-validation; and published two interactive Tableau dashboards.
Result
The quality checks changed a conclusion: an apparent jump in walking speed came from a change in how the device estimated stride length, not from a gain in fitness. In the published (simulated-data) version, the forecast was 13% more accurate than the best simple rule (mean absolute error).

Analysed first on my own tracker data, then published with a simulated version of the activity data to protect privacy.

Python · SQL (DuckDB) · regression · forecasting · Tableau

Air-HOLP and the AirScreen R package

2024–2025 · Research · first author · method and software

Problem
In data with thousands of possible factors, such as gene-expression data, find the few that really affect the outcome, even when the factors are strongly related.
What I did
Created Air-HOLP, a statistical method that extends an existing screening method (HOLP) with ridge regularisation that tunes itself, so no slow resampling is needed. Tested it across many simulated settings and on prostate cancer gene-expression data.
Result
Published as first author in Statistics and Computing (2025) and released on CRAN as AirScreen, an R package with unit tests.

R · feature selection · simulation studies · testthat

Synthetic data with generative AI

2024 · Research · co-author

Problem
Can synthetic student records protect privacy and still support accurate prediction of learning outcomes?
What I did
Generated synthetic data with generative AI models (CTGAN and CopulaGAN), checked it against the real data (distributions, correlations and principal-component structure), and compared prediction on original, synthetic and combined data. My part: methodology, software and visualisation.
Result
Published in Computers and Education: Artificial Intelligence (2024). I also co-authored research that integrates generative AI with feature selection for high-dimensional cancer classification (IEEE ICDH 2026).
